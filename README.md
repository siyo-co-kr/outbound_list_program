# 🏥 아웃바운드 리스트 자동화 도구 (Outbound List Tool)

병원 실무에서 반복되던 **엑셀 기반 환자 리스트 정제 작업**을 자동화하기 위해 만든 Python 데스크톱 애플리케이션입니다.
암호화된 엑셀, 병원마다 제각각인 컬럼명, 형식이 뒤섞인 전화번호 데이터를 사람이 손으로 다듬던 과정을 프로그램 하나로 대체하는 것을 목표로 개발했습니다.

## 📌 프로젝트 배경

병원 마케팅/안내 문자 발송을 위해서는 매번 아래와 같은 반복 작업이 필요했습니다.

- 전자차트에서 내려받은 **암호화된 엑셀 파일**을 수작업으로 복호화
- 병원 시스템마다 다른 컬럼명(`연락처` / `휴대폰번호` / `전화번호` 등)을 매번 확인하며 정리
- 하이픈, 공백 등이 섞인 전화번호를 하나씩 다듬고 중복을 제거
- 내원일·생년월일 기준으로 원하는 대상자만 골라내는 필터링을 엑셀 함수로 수작업 처리

이 과정에서 발생하는 **시간 낭비와 휴먼 에러(오타, 누락, 중복 발송 등)** 를 줄이기 위해, 이 도구는 파일 선택 → 옵션 설정 → 저장 세 단계만으로 동일한 작업을 몇 초 안에 끝낼 수 있도록 설계했습니다.

## 🚀 주요 기능

- **암호화 엑셀 지원**: 비밀번호가 걸린 엑셀 파일도 프로그램 내에서 즉시 복호화하여 처리
- **원본 표기 보존**: 모든 값을 문자열로 읽어 텍스트 서식으로 저장된 `00123`의 앞자리 0이 사라지지 않으며(숫자 서식 셀은 엑셀 단계에서 이미 0이 지워짐), 엑셀이 앞자리 0을 지운 번호(`1012345678`)와 `+82` 국제 표기는 자동 보정
- **날짜 형식 자동 인식**: 엑셀 날짜 셀, `2026-07-01` 문자열, `20260701` 숫자, 엑셀 일련번호를 모두 해석
- **컬럼명 유연 매칭**: 병원마다 다른 컬럼명을 표준 항목에 자동으로 매핑하며, 후보가 여러 개면 정해진 우선순위로 선택하고 어떤 컬럼을 썼는지 알림 (`column_utils.py`)
- **시트·머리글 자동 탐색**: 머리글이 첫 행이 아니거나 데이터가 다른 시트에 있어도 필수 컬럼이 있는 위치를 찾아 읽음
- **필터링 조건**: 마지막 내원일 기준 **최근 N개월/년** 필터와, 반대로 **오래 미내원한 대상만** 골라내는 필터를 동시에 지원. 생년월일 범위로 연령대 타겟팅
- **전화번호 정제**: 특수문자 제거 → 형식 검증 → 중복 제거 순으로 처리
- **처리 내역 표시**: 어느 단계에서 몇 건이 걸러졌는지 완료 창에 함께 표시해, 의도한 대로 필터링됐는지 확인 가능
- **양식 그대로 출력**: 결과를 `resources/outbound_template.xlsx` 양식 그대로 저장 (`차트번호 / 환자 이름 / 휴대폰번호` + 우측 작성예시 블록)

## 🛠 기술 스택 & 설계 포인트

| 영역 | 사용 기술 | 비고 |
| :--- | :--- | :--- |
| GUI | tkinter / ttk (표준 라이브러리) | 추가 설치 불필요 |
| 데이터 처리 | pandas, python-dateutil | 필터링·정제 로직 |
| 엑셀 처리 | openpyxl, xlrd, msoffcrypto-tool | 암호화 엑셀 복호화 및 템플릿 서식 유지 |
| OS 연동 | ctypes (COM `IShellLink`) | 바탕화면 바로가기 생성 |
| 배포 | PyInstaller | 단일 exe 빌드 |

**설계에서 신경 쓴 부분**

- **UI / 비즈니스 로직 분리**: `app_modules/ui_components`(화면)와 `app_modules/processors`(순수 데이터 처리 함수)를 분리해, 로직만 따로 테스트하거나 CLI로도 재사용할 수 있는 구조로 설계했습니다. 덕분에 GUI를 PySide6에서 tkinter로 교체할 때 처리 로직은 손대지 않았습니다.
- **컬럼명 유연 매칭**: 정규식으로 특수문자·공백을 제거한 뒤 후보 컬럼명 목록과 매칭하는 `resolve_columns()`을 두어, 병원 시스템이 바뀌어도 코드 수정 없이 대응할 수 있게 했습니다. 후보를 "구체적인 이름일수록 앞"으로 정렬해 두어 파일의 컬럼 순서에 결과가 좌우되지 않고, 이미 배정된 컬럼은 재사용하지 않아 서로 다른 항목이 같은 컬럼을 가리켜 값이 뒤섞이는 일이 없습니다.
- **원본 표기 보존**: 엑셀을 전부 문자열로 읽습니다. pandas의 자동 타입 추론에 맡기면 `00123`이 `123`이 되어 앞자리 0이 사라지고, 빈칸이 섞인 숫자 컬럼은 `1012345678.0`처럼 소수점이 붙어 연락처가 통째로 유실됩니다. 대신 날짜는 형식별로 나누어 해석하는 전용 파서를 두었습니다.
- **검증 가능한 결과**: 단계별로 몇 건이 걸러졌는지 집계해 완료 창에 함께 보여줍니다. 조용히 사라지는 데이터가 없도록, 날짜를 해석하지 못했거나 컬럼 후보가 여러 개였던 경우도 함께 알립니다.
- **양식 재현이 아닌 양식 사용**: 결과 파일의 서식을 코드로 흉내 내지 않고 템플릿 엑셀 파일 자체를 열어 값만 채웁니다. 글꼴·머리글 색·테두리·열 너비가 원본과 100% 일치하며, 양식이 바뀌어도 템플릿 파일만 교체하면 됩니다.
- **체감 속도 개선**: `pandas`, `msoffcrypto` 등 무거운 모듈을 스플래시 화면 표시 이후에 지연 임포트(lazy import)하여, exe 실행 시 첫 화면이 뜨기까지의 체감 대기 시간을 줄였습니다.
- **배포 편의성**: PyInstaller로 빌드한 최초 실행 시, OneDrive 리다이렉트 환경까지 고려해 바탕화면 바로가기를 자동 생성합니다. 외부 프로세스(`powershell.exe`) 대신 COM `IShellLink`를 직접 호출하므로 `PATH` 환경변수가 깨진 PC에서도 동작하며, 실패하더라도 본 기능 실행에는 영향이 없습니다.
- **로컬 처리 원칙**: 개인정보(환자 데이터)를 다루는 도구이므로 외부 서버 전송 없이 전 과정을 로컬에서만 처리합니다.

    ├── conftest.py                           # 엑셀 파일 생성 픽스처
    ├── test_column_utils.py
    ├── test_parsing.py                       # 날짜·연락처 파싱

    ├── test_filter.py                        # 필터 전체 흐름
    └── test_template_writer.py

## 🖥 실행 방법

**요구 사항**: Python 3.8+ (개발 환경 3.12)

```bash
pip install -r requirements.txt
python main.py
```

**테스트**

처리 로직은 UI에 의존하지 않으므로 GUI 없이 그대로 실행됩니다.

```bash
pytest tests
```

**실행 파일(EXE) 빌드**

결과 양식 파일(`resources/outbound_template.xlsx`)을 번들에 포함해야 하므로 spec 파일로 빌드합니다.

```bash
pyinstaller --noconfirm Outbound_filter_tool.spec
```

## 📖 사용 방법

1. [파일 찾기]로 원본 환자 정보 엑셀 파일 선택
2. 암호가 걸려 있다면 비밀번호 입력 (없으면 공란)
3. 내원일 필터 설정 (두 가지를 함께 사용 가능)
   - **3번 필터**: 설정 기간 **이내에** 내원한 대상만
   - **4번 필터**: 설정 기간보다 **오래 미내원한** 대상만
4. 필요 시 생년월일 범위 설정 (`YYYY-MM-DD` 형식 입력)
5. [필터링 및 저장] 클릭 → 템플릿 양식으로 새 엑셀 파일 저장
6. 완료 창의 **처리 내역**에서 단계별로 몇 건이 걸러졌는지 확인

## ⚠️ 데이터 요구 양식

시트가 여러 개면 **두 번째 시트**를 우선으로 보고, 거기서 필수 컬럼을 찾지 못하면 다른 시트와 머리글 행(최대 8행)까지 탐색합니다.

| 컬럼명 | 필수여부 | 설명 |
| :--- | :---: | :--- |
| **차트번호** | 필수 | 환자 고유번호 (원본 표기 그대로 출력, 앞자리 0 유지) |
| **이름** | 필수 | 환자 성함 |
| **연락처** | 필수 | 휴대전화 번호 (010 형식으로 자동 보정) |
| **마지막 내원일자** | 필수 | 최종 방문일 (내원일 필터 기준) |
| **생년월일** | 선택 | 생년월일 필터 사용 시 필수 |

컬럼명은 정확히 일치할 필요가 없습니다. 예를 들어 연락처는 `휴대폰번호`, `핸드폰번호`, `연락처`, `전화번호` 등을 인식합니다. 한 파일에 후보가 둘 이상 있으면 더 구체적인 이름을 우선 사용하고, 어떤 컬럼을 썼는지 완료 창에 표시합니다.

## 💡 참고 사항
- **중복 제거**: 동일한 연락처가 있을 경우, 형식 검증을 통과한 뒤 먼저 등장한 행만 남기고 중복은 제거됩니다.
- **제외 데이터 통보**: 날짜를 해석하지 못했거나 연락처 형식이 맞지 않아 제외된 건수는 완료 창에 표시되므로, 조용히 누락되지 않습니다.
- **보안**: 데이터를 외부 서버로 전송하지 않으며, 로컬 환경에서만 처리합니다.
